# Oyo-Hospitality
1. Project title: OYO Hospitality dashboard.
   A dynamic data visualization to represent performance of OYO property across the nation focusing on their Revenue, Occupancy ,       business through various channels, comparison through various business metrics and identify the trends at weekdays and weekend.

2. Description.
   The OYO Hospitality is a visually appealing ,analytical dashboard to help user to explore and compare over 25 property across
   4 states in 3 months through week over week comparison , using various business metrics like REVPAR , DSRN,DURN, ADR, OCCUPANCY
   and REVENUE. Allow user to compare performance of their property through 7 channels, to identify the pattern through                 category(business or luxury).

3. Tool Stack.
   The dashboard was built using following tools and technologies,
    Power Bi Desktop - Main data visualization platform used for Report creation.
    Power Query      - Data cleaning, preparation and reshaping the data .      
    Data  Modelling  - Relation established between fact tables and dimension table
    DAX (Data Analytical Expression)- Used to create measure, columns, time intelligence function for week over week comparison.
    File format      - pbit for development and png for previews

5. Data source
   Codebasics Data challenge. 5 underlying tables about 13490 rows 

5.Highlights
 Business problems To identify the underperforming property, reason and scope of improvement
 Trends to identify pattern to implement dynamic pricing, demand and supply opportunity. weekday and week end strategy
 Key insight  -Online rating directly impact occupancy eventually revenue.
              -Flat ADR represent no dynamic pricing according demand and supply not even on weekends
              -No differential pricing on their on channel/website
